## PAWSON AI in 30 seconds

| Business intelligence | Expert collaboration | Content production |
| --- | --- | --- |
| Uses trusted operating data and separates facts, inferences, and unknowns | Brings visual diagnosis, business analysis, and document delivery into one agent workspace | Turns product assets, image processing, and mockups into recoverable project workflows |

PAWSON AI is a Windows desktop workspace for cross-border commerce and content operations. Within user-approved boundaries, the agent can use business context, invoke specialized capabilities, work with real files, and return results to product workflows.

The project emphasizes local-first storage, traceable evidence, approval for sensitive actions, and recoverable failure states. A success message in the UI is never treated as proof that a business operation or external service actually succeeded.

## Current status

> **Current focus: commercial AI access and request-level verification**
>
> The latest isolated runtime probe contains 16 cases: 15 passed, while one exposed a cancellation propagation gap. The existing agent core remains in place. Real gateway behavior, provider-side metering, and multi-tenant concurrency still require further verification.

Between late July and early September 2026, the private source repository accumulated 315 real commits. PAWSON evolved from an image-production tool into a platform with data assets, business dashboards, knowledge bases, project workspaces, a unified agent entry point, and specialized expert capabilities. The product entered its 2.0 stage on September 9, 2026.

## About this public repository

This repository shares product evolution, user value, verified results, design decisions, and reviewed project visuals. It is a living development story, not a mirror of the private source repository.

Source code, full architecture, internal APIs, database schemas, deployment configuration, system prompts, credentials, customer information, and reproducible core implementation details remain private.
