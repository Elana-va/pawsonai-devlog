# POD 智造 Beta 1.0.0-rc.1

**简体中文** · [English](1.0.0-rc.1.en.md)

发布日期：2026-07-25

这是 PAWSON 产品演进中的早期交付节点，包含 Windows 安装版与便携版，以及商品图片生产、商品信息采集、自动工作流和商业控制能力的首套组合。

## 公开能力摘要

- 文字生成图片、参考图生成和基础视频任务。
- 本地抠图、裁剪、图片放大和模板展示。
- 商品与变体信息采集，并保留来源关系。
- 可恢复任务、人工复核节点和安全导出。
- 企业、设备、套餐额度、远程任务与加密备份基础。

## 验证摘要

- 51 个测试文件、152 项测试通过。
- Windows 安装版与便携版构建成功。
- 打包应用完成多项实际图片处理验证。

## 已知边界

当时的安装程序尚未使用商业代码签名证书。外部模型效果、价格和可用性仍需使用合法账号进行独立验收。
