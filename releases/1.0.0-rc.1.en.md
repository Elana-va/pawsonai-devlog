# POD Studio Beta 1.0.0-rc.1

[简体中文](1.0.0-rc.1.md) · **English**

Release date: July 25, 2026

This was an early delivery milestone in PAWSON's evolution. It combined Windows installer and portable builds with the first set of product-image production, product-data collection, automated workflow, and commercial-control capabilities.

## Public capability summary

- Text-to-image, reference-image generation, and basic video tasks.
- Local background removal, cropping, image upscaling, and template previews.
- Product and variant data collection with source relationships preserved.
- Recoverable tasks, human review points, and safe export.
- Foundations for organizations, devices, plan quotas, remote tasks, and encrypted backups.

## Verification summary

- 51 test files and 152 tests passed.
- Windows installer and portable builds succeeded.
- The packaged application completed multiple real image-processing checks.

## Known limits

The installer did not yet use a commercial code-signing certificate. External model quality, pricing, and availability still required independent acceptance with a legitimate account.
