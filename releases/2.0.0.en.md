# PAWSON AI Platform 2.0.0

[简体中文](2.0.0.md) · **English**

Release date: September 9, 2026

Version 2.0 unified the desktop product, control center, reporting, and product-collection extensions under the PAWSON AI Platform brand, bringing NEW PAWSON AI and expert capabilities into one workspace.

## Changes in this release

- Unified product branding and desktop experience.
- Added the new Agent workspace and expert capabilities.
- Improved AI gateway authorization boundaries.
- Preserved existing business, asset, template, product-detail, and task capabilities.
- Maintained compatibility with accounts, credits, local data directories, and update protocols.

## Note

Release notes describe the public delivery scope without exposing internal deployment configuration, provider credentials, or complete technical implementation.
