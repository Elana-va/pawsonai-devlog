# September 8, 2026: The General AI Gateway Completed Its First Path

[简体中文](2026-09-08.md) · **English**

## Why the access boundary changed

The previous capability router tied provider choice, long-lived credentials, and desktop release cycles too closely together. It was also difficult to reuse safely across text, image generation, image editing, and future video capabilities. The product needed one provider-neutral path with short-lived authorization and independent acceptance.

## Completed that day

- Retired the previous multi-provider capability router while preserving required compatibility data and avoiding destructive migration.
- Established a versioned capability contract covering Agent, text, image-generation, image-editing, and video call shapes.
- Enabled the control center to issue least-privilege short-lived leases to eligible signed-in identities, with public information for independent signature verification.
- Kept long-lived provider secrets out of the desktop client, renderer process, ordinary logs, and control-center responses.
- Connected NEW PAWSON AI through the first desktop-to-gateway Agent path without silently falling back to a model with unknown cost.
- Began reusing the same capability boundary for text-to-image, pattern variations, and product-detail text and image transport.
- Sent model request content directly to the AI gateway while the PAWSON control center handled eligibility, capabilities, and short-lived authorization.

## Verification evidence

- Relevant unit and integration tests, type checks, the control-center build, and the desktop production build passed.
- The first live Qwen text path and consumer authorization passed hands-on acceptance.
- Image workflows retained existing compression, format, and task-persistence boundaries while changing transport.

## Still incomplete

Trusted commercial usage reconciliation was not complete. Balance gating and client-side results cannot replace trusted gateway or provider metering, so this stage confirmed the access path without claiming that commercial billing was finished.
