# August 21, 2026: The Agent MVP Became the Main Product Line

[简体中文](2026-08-21.md) · **English**

## Why we shifted toward an Agent

As business, image, reporting, and task features grew, separate AI pages could no longer carry complete work. Users needed one entry point that could understand the current task, apply different capabilities, and retain the process.

## Milestones completed

- Established the foundation for persistent conversations and task states.
- Combined specialist capabilities with conversation context.
- Improved recovery and input preservation after runtime failures.
- Created a stable PAWSON Agent MVP baseline.

## Product judgment

An Agent's value goes beyond answering questions. It must know where work stands, when user approval is required, how to deliver real files, and how to continue after a failure.

## Next

Make web collection, data assets, the knowledge base, and product projects trusted context that the Agent can use safely.
