# 2026-08-21：Agent MVP 成为产品新主线

## 为什么转向 Agent

随着经营、图片、报告和任务功能增加，单独的 AI 页面已经无法承接完整工作。用户需要的是一个能理解当前任务、使用不同能力并保留过程的统一入口。

## 完成的节点

- 建立持续对话和任务状态基础。
- 将专业能力与会话上下文结合。
- 补强运行失败后的恢复与输入保留。
- 形成 PAWSON Agent MVP 稳定基线。

## 产品判断

Agent 的价值不只是回答问题。它需要知道任务进行到哪里，什么时候必须等待用户批准，怎样交付真实文件，以及失败以后如何继续。

## 下一步

让网页采集、数据资产、知识库和商品项目成为 Agent 可以安全使用的可信上下文。
