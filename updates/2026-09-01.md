# 2026-09-01：Agent 从回答问题走向处理文件和长任务

**简体中文** · [English](2026-09-01.en.md)

## 本阶段完成

- 增加受控的本地命令执行能力。
- 支持长任务状态、停止、失败恢复和过程产物。
- 生成文件可以显示、打开并在重启后继续访问。
- 加载文档与表格等办公能力。
- 建立外部 Skill 的发现、检查和加载流程。

## 必须守住的边界

命令并不因为由 Agent 提出就自动安全。读取、写入、发送和发布需要不同权限；敏感动作等待用户批准。生成文件也要检查真实存在，不能让占位卡片或旧缓存冒充交付成功。

## 这次变化的意义

Agent 开始具备完成工作所需的执行与交付能力，同时把审批、恢复和证据放在能力扩展之前。
