# September 9, 2026: Entering the PAWSON AI Platform 2.0 Stage

[简体中文](2026-09-09.md) · **English**

## Product changes

The desktop product, control center, reporting, and collection extensions were unified under the PAWSON AI Platform brand. The new Agent became the main product line while legacy runtime paths began to retire.

## Completed in this stage

- Established a versioned model catalog and per-conversation model selection.
- Connected to the unified AI gateway with short-lived authorization data.
- Restored webpage reading, web search, source links, and pluggable capabilities.
- Isolated 2.0 data from legacy local state.
- Preserved compatibility with existing accounts, credits, data directories, and update protocols.

## Verification boundary

The code, tests, and build baseline were established, but real model responses still require an authorized service environment with the correct configuration. A request that never reached a model provider is not described as a successful real call.
